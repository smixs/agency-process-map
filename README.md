# Агентский процесс — интерактивная карта

Интерактивная карта агентского процесса: **5 этапов** от брифа до презентации, **44 узла**, связи (потоки данных, связи по содержанию, синергии) и пресет-маршруты.

🔗 **Live:** https://agency-process.com

Брифинг → Стратег → Креатор → Продюсер → Презентер.

## Возможности

- **Swimlane-граф** на [React Flow](https://reactflow.dev): этапы — горизонтальные уровни сверху вниз, узлы соединены аккуратными `smoothstep`-рёбрами через порты.
- Рёбра окрашены по этапу-источнику; клик по узлу подсвечивает его связи и центрирует камеру.
- Пресет-маршруты (лонч, атака на конкурента, рост частоты, доверие, премиализация), фильтр по типам связей, поиск.
- Pan колесом/тачем + pinch-зум, сворачиваемая панель, выезжающий drawer деталей, полноэкранный режим.
- Светлая высоко-контрастная тема, mobile-first.

## Стек

Vite · React 19 · TypeScript · React Flow (`@xyflow/react`) · dagre (`@dagrejs/dagre`). Чистый CSS с дизайн-токенами.

## Разработка

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # сборка в dist/
pnpm preview
```

Данные процесса — единый источник правды в [`src/data/processMap.ts`](src/data/processMap.ts).

## Ассеты (favicon, OG-превью)

Генерируются из SVG-исходников (`public/favicon.svg`, `scripts/og.svg`):

```bash
node scripts/gen-assets.mjs
```

## Деплой

Хостинг — Vercel (Vite-пресет, выходная папка `dist/`). Пуш в `main` автоматически уходит в production.
