# Implementation notes — Agency Process Map (React)

Живой журнал решений по пересборке инфографики. Спека: план `woolly-swimming-boole.md`.

## 2026-06-09

### Decisions
- **Стек**: Vite 8 + React 19 + TypeScript (scaffold react-ts). Деплой — Vercel (статика). Решение пользователя.
- **Данные**: всё ядро (`STAGES/NODES/LINKS/ROUTES`) перенесено дословно в `src/data/processMap.ts` с TS-типами. Координаты x/y/w исходника отброшены — вертикальную раскладку считает CSS. 44 узла, ~80 связей, 6 маршрутов.
- **Цвета этапов**: переопределены под светлую тему (исходные #60a5fa и т.п. — для тёмной). Новые насыщенные: brief #2563eb, strategy #7c3aed, creator #db2777, producer #ea580c, presenter #0d9488.
- **kind узлов**: в исходнике у всех узлов `kind:'doc'`. Маркеры «висящий» (🚩) и «дополнено» (доп.) живут на уровне опций и связей (`added:true`), не узлов. Поэтому поле node.kind не переносил — храню маркеры в опциях/связях как в оригинале.
- **Стили**: единый глобальный `src/styles/theme.css` вместо CSS-модулей. KISS: один файл токенов+классов, без настройки. App single-purpose.
- **Зум**: CSS `transform: scale` на `.mapContent`; внешний `.zoomWrapper` сайзится в JS как `designW*scale × contentH*scale` (чтобы скроллбары соответствовали). `designW` = ширина вьюпорта, `contentH` = `offsetHeight` контента — обе меряются ResizeObserver. Координаты связей — натуральные (offset), от зума не пересчитываются.
- **Связи**: SVG-оверлей внутри `.mapContent`. По умолчанию рисуем связи только активного узла (selected/hover) и активного маршрута — против спагетти и под презентацию. Тумблер «все связи». Спайн этапов 1→5 — CSS (вертикальная линия в левом жёлобе), не SVG.
- **Mobile-first** (требование пользователя): базовые стили — мобильные (1 колонка, sidebar и details — overlay/bottom-sheet). Медиа-запросы ≥768/≥1024 разворачивают сетку карточек (`auto-fill minmax`) и делают панели в потоке. Тач-pinch — нативный зум страницы (viewport user-scalable), ctrl+wheel (трекпад/desktop) — наш transform-зум.

### Редизайн (после фидбэка: «generic, где связи?»)
Первая версия была AI-slop: одинаковые карточки с толстой полоской-слева, generic-тени, шрифт Inter, связи спрятаны по умолчанию. Прочитал skill `frontend-design` (анти-паттерны) и `ui-ux-pro-max`. Решение пользователя: **светлая, но модная** тема + связи должны быть видны.
- **Направление**: светлая редакционная подача. Премиум-фон (dot-grid + мягкие aurora-пятна), крупные контурные номера этапов `01..05`, тонированные тайлы (фон = stage-hue 6% на белом, без полоски-слева), сетка узлов `auto-fill minmax(250)`.
- **Типографика**: Space Grotesk (display) + DM Sans (body) через Google Fonts в `index.html`. Не Inter.
- **Палитра этапов**: продуманный спектр indigo/sky/pink/orange/emerald (`STAGES` в processMap.ts).
- **Связи видимы**: `showAllLinks` по умолчанию `true`; SVG-рёбра с «потоком» (анимация stroke-dashoffset) + halo; в покое деликатно (opacity 0.3), на фокусе ярко, остальные гаснут. На экранах <768px линии скрыты (в одну колонку центры совпадают → бесполезная полоса); связи там — через drawer узла.
- **Иконки**: убраны emoji-глифы из UI (контролы/закрытие → SVG), по правилу skill `no-emoji-icons`. Эмодзи в опциях узлов (🚩, 🔴🟡🟢) — это контент методики, оставлены.
- Все экраны проверены через Claude Preview (desktop 1280/1440, mobile 375). Build чистый.

### Пивот на React Flow (после фидбэка: связи кривые/обрываются/без уровней, тач не работает)
Самопальный SVG-оверлей давал спагетти и «обрывы». Перешёл на индустриальный стандарт **React Flow `@xyflow/react` v12** + **`@dagrejs/dagre`** (как ComfyUI/n8n).
- **Связи как надо**: ноды соединяются портами-`Handle` (top target / bottom source), рёбра `smoothstep` со скруглением, рисуются ПОД нодами, стрелки. Цвет ребра = цвет этапа-ИСТОЧНИКА. Фокус: связи выбранного узла ярко + анимация потока, остальные гаснут; выбранный узел центрируется (`fitView` к ноде).
- **Уровни сохранены (swimlane)**: `bandedLayout` в `flow/graph.ts` — каждый этап это горизонтальная полоса-уровень сверху вниз; внутри полосы под-dagre TB по ВНУТРИэтапным связям; межэтапные рёбра текут вниз. Полосы рисуются через `ViewportPortal` под нодами (`z-index:-1`), с крупной подписью `01 Брифинг` слева.
- **Pan/zoom**: `panOnScroll` (Free) + `zoomOnScroll=false` + `zoomOnPinch` — колесо/тач двигают карту, pinch/⌃+колесо зумят. Зум-кнопки через `useReactFlow`.
- **pnpm + React Flow**: «Invalid hook call / more than one copy of React» лечится `resolve.dedupe:['react','react-dom']` в `vite.config.ts`.
- **Mobile touch fix**: `maximum-scale=5` отдавал pinch нативному зуму браузера и ломал жесты в графе → поставил `maximum-scale=1, user-scalable=no`, теперь pan/pinch идут в React Flow. На <768px miniMap/attribution скрыты.
- Маршруты в сайдбаре покрашены (ROUTE_COLORS), добавлена легенда этапов.
- Старые компоненты scroll-версии (MapCanvas/StageSection/LinkLayer/NodeCard) удалены.
